# Cost Breakdown Structure - ASF HRM UX Design

## Phase-wise Effort Distribution

### Phase 1: Planning & Research (10 Man-Days)
| Task | Man-Days | Description |
|------|----------|-------------|
| Requirements Analysis & Documentation | 3 | Detailed analysis of functional requirements and SRS alignment |
| User Persona Development | 2 | Creation of target user profiles and behavioral patterns |
| Information Architecture Design | 3 | Complete sitemap and navigation structure definition |
| Competitive Analysis | 2 | Market research against global HRM standards |

### Phase 3: Visual Design (28 Man-Days)
| Task | Man-Days | Deliverable |
|------|----------|-------------|
| Design System Creation | 5 | Typography, colors, components library |
| High-Fidelity UI Mockups (All Modules) | 15 | Pixel-perfect designs for all 11 modules |
| Interactive Prototype Development | 5 | Clickable prototype for user testing |
| Design Documentation & Handoff | 3 | Developer handoff documentation |

### Project Management & QA (10 Man-Days)
| Task | Man-Days | Purpose |
|------|----------|---------|
| Project Coordination & Client Communication | 5 | Weekly reviews, status updates, stakeholder management |
| Design Reviews & Iterations | 5 | Quality assurance, revision cycles, final approvals |

## Total Project Summary
- **Total Man-Days:** 73
- **Phase Distribution:** Planning (14%) → Wireframing (34%) → Visual Design (38%) → PM/QA (14%)
- **Timeline:** 13 weeks across 3 structured phases
- **Quality Assurance:** 2 revision rounds per phase included
